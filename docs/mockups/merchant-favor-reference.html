A Waylaid Crate, filled with any one of its listed material bundles, becomes a Sealed Crate turned in for Merchant's Favor. Cost is always TSM's realm-level Recent Value for the crate itself and every possible fill material — the cheapest fill option is picked automatically, since any one of them works. Ranked by cost per Favor, not raw cost — a pricier crate can still be the better deal if it pays enough more Favor. Favor amounts are estimated — choosing a target number of tokens is still planned, pending the hand-in-quest mapping.
